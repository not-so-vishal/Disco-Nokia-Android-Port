# Disco Android Port

An unofficial, vibe-coded Android port of the classic Nokia Java ME game Disco.

## About the Project

This project aims to bring the original Nokia mobile game Disco to Android as an Android application.

**This is an actual port, not just an emulator wrapper.**

The original game's code has been adapted to work within an Android application. The project includes Android-side rendering, input handling, and compatibility implementations for the Java ME APIs used by the game.

This is a **vibe-coded project**, developed with AI assistance to help write, adapt, debug, and improve the code.

## Features

- Android application built with the Android development toolchain
- Adapted original game logic
- Android-side graphics rendering and input handling
- Compatibility implementations for relevant Java ME APIs
- Gradle-based build system
- Designed to run as an Android app rather than simply wrapping a Java ME emulator

Some features may be incomplete, and compatibility can vary by device.

## Repository Contents

This repository contains the Android port's source code and build configuration.

Original game assets and reference files are excluded from the source repository. The separately built APK may contain game assets required to run the game.

## Building the Project

1. Clone or download this repository.
2. Open the project in a compatible Android development environment.
3. Ensure any required local game assets are available in the expected location.
4. Build the application using the included Gradle wrapper.

The build may require local game assets that are intentionally not included in this repository.

## Project Status

This is a work in progress. Gameplay, sound, rendering, compatibility, performance, and device support may change as development continues.
